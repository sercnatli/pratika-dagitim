# pratika-dagitim

Pratika **dağıtım kanalı** (public — istemciler token’sız okur):
- `app-version.json` — sürüm + installer linki (otomatik güncelleme)
- `veri-panel.json` — Gizli Veri Paneli şifre hash’i (yalnız salt+hash)
- Releases — `PratikaSetup.exe`

`pratika-updates` + `pratika-veri` birleşimi.
